# Git Activities Evidence — LC3-Navigator

โฟลเดอร์นี้รวบรวมหลักฐานการทำงานร่วมกันของกลุ่มที่ 2 สำหรับโครงงาน **ระบบนำทางภายในอาคารคณะวิทยาศาสตร์ บร.3 (LC3-Navigator)**

หลักฐานในโฟลเดอร์นี้จัดทำขึ้นเพื่อให้อ่านแล้วเข้าใจได้ว่า

- ทีมแบ่งงานอย่างไร
- สมาชิกแต่ละคนรับผิดชอบงานส่วนใด
- งานแต่ละส่วนเชื่อมกับระบบรวมอย่างไร
- ทีมใช้ Trello, GitHub และ Discord สนับสนุนการทำงานร่วมกันอย่างไร
- มีหลักฐาน non-code เช่น architecture diagram, setup summary, teamwork evidence และ demo link
