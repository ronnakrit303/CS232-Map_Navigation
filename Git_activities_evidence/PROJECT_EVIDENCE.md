## ภาพรวมหลักฐานการทำงาน

ทีมใช้เครื่องมือหลัก 3 ส่วนในการทำงานร่วมกัน ได้แก่ Trello, GitHub และ Discord โดยมีบทบาทต่างกันดังนี้

| Tool | บทบาทในโครงงาน |
|---|---|
| Trello | ใช้เป็น task board หลักสำหรับแบ่งงาน กำหนดสมาชิกในแต่ละ task ติดตามสถานะ และแนบ artifact ของงาน |
| GitHub | ใช้เก็บ source code, config, documentation, workflow และไฟล์หลักที่เกี่ยวข้องกับระบบ |
| Discord | ใช้สื่อสารภายในทีม แจ้งการ update งาน แชร์ link เครื่องมือ และแจ้ง commit / push ที่สำคัญ |

## การใช้ Trello แทน GitHub Issues

ทีมไม่ได้ใช้ GitHub Issues เป็นช่องทางหลักในการติดตามงาน แต่ใช้ **Trello Board** เป็น task list หลักแทน โดย Trello มีการแบ่งสถานะงาน เช่น To do, Doing และ Done รวมถึงมี label ตาม user story เช่น GLOBAL, US1, US2, US3, US4, US5, US6 และ US7

Trello board ยังแสดงข้อมูลที่ใช้เป็นหลักฐานได้ เช่น

- ชื่อ task
- รายละเอียดงาน
- สมาชิกที่รับผิดชอบ
- checklist / DOD
- artifact ที่แนบกับการ์ด
- ความคืบหน้าของงานจาก To do / Doing / Done

Trello Board: https://trello.com/b/wB1GFvrX/sprint-planningnavigationsystem

## หลักฐาน Non-code ใน Repository

นอกจาก source code แล้ว repository มีเอกสารและ artifact ที่ช่วยอธิบายระบบ เช่น

- Architecture diagram ของ AWS Serverless Architecture
- Admin Guide สำหรับการอัปเดต config
- config format และ config examples
- setup / deployment summary
- teamwork evidence PDF
- test evidence และ demo video
